# Mock Exam Screenshots

This folder contains screenshots of mock exam questions with answers and explanations.

## Structure

- Each image should be a PNG screenshot containing:
  - Question text
  - Answer options
  - Correct answer indication
  - Explanation of the correct answer

## Total Images

Expected: 134 mock exam question screenshots

## Processing

Once all images are uploaded, run the extraction script to process these images and extract:
- Question text
- Answer options
- Correct answer
- Explanation text

The extracted data will be saved in a structured format for the exam study app.
